# Product photos

Upload the original product photos here (JPG, PNG or WebP, any size). Name each file after the gift's **ID** in the Catalogue tab, e.g. `hario-mug.jpg`.

On every publish, GitHub turns them into small WebP images (400 px and 800 px wide) for the website. Then put the same name (e.g. `hario-mug.jpg` or just `hario-mug`) in the Catalogue tab's **Image** column.

Photos on a plain white or light background look best with the page design.
